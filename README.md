# 🌌 星途 SPO · 世界观共创平台 (SPO Co-Creation Platform)

欢迎来到 **星途 SPO** 核心世界观协同创作平台！

本项目是基于 GitHub 的开放式科幻世界观共创基地。无论是设定研讨、文献查阅，还是故事撰写与沙盒跑团模组共创，创作者都可以通过现代化的 Web 工作台直接协同编辑与交流。

* **平台在线地址**：👉 [https://spo-web-frontend-6v8e.vercel.app](https://spo-web-frontend-6v8e.vercel.app)
* **设定文本仓库**：[Parzervil/SPO-Co-Platform](https://github.com/Parzervil/SPO-Co-Platform)

---

## 🚀 创作者极速上手指南 (3步开启共创)

想要在星途宇宙中留下你的设定与故事？只需以下简易三步：

### 第一步：获取仓库协作者权限
联系仓库管理员（[@Parzervil](https://github.com/Parzervil)）将你的 GitHub 账号添加为本仓库的 **协作者 (Collaborators)**。

### 第二步：访问共创工作台
打开已部署上线的共创前端应用：
🔗 **[https://spo-web-frontend-6v8e.vercel.app](https://spo-web-frontend-6v8e.vercel.app)**

### 第三步：点击登录
在网页端点击 **「GitHub 登录」** 授权，系统将自动校验协作者权限并为你初始化创作工作区，即可开始阅读、编辑与发表提案！

## 🧭 平台核心功能与工作流

```text
┌─────────────────────────────────────────────────────────────┐
│                   星途 SPO 世界观共创工作台                  │
├─────────────────┬─────────────────────────┬─────────────────┤
│  官方白皮书体系  │     知识库 (知识引擎)    │  协作中心 (动态)│
│                 │                         │                 │
│  • 00 白皮书     │  • 个人工作区 (专属)    │  • 设定提案评审 │
│  • 01 星途百科   │  • 团队工作区 (Public)  │  • 跑团模组探讨 │
│  • 02 星途志异   │  • 在线富文本/MD 编辑   │  • 设定修订公议 │
│  • 03 沙盒跑团   │  • 自动同步至本仓库     │  • 跨时空脑洞   │
└─────────────────┴─────────────────────────┴─────────────────┘
```

### 1. 📜 官方白皮书体系 (`/dashboard/whitepaper`)
* **权威世界观基石**：收录了全宇宙大事件编年史（泛星历 P.E.）、阵营与种族图谱（索拉联合、莫汝拉帝国、罅隙星区）、科技红线、深空奇观等全量核心文献。
* **三级目录沉浸阅读**：无干扰极简排版，支持宋体/黑体切换、字号无级调节、右侧章节大纲平滑跳转与连贯翻页。

### 2. 🧠 知识库 · 知识引擎 (`/dashboard/knowledge`)
* **个人独立工作区**：每位协作者拥有专属的命名空间文件夹（如 `knowledge_base/<你的GitHub用户名>/`），他人仅可阅读，只有你拥有编辑权限。
* **公共协作沙盒**：支持在 `设计（Public）` 与 `IDEAS（Public）` 目录中创建公开文档，所有协作者均可共同探讨与修改。
* **实时云端同步**：在 Web 端编辑保存后，自动转换为标准 Markdown 提交至本仓库。

### 3. 💬 协作中心 (`/dashboard/discussions`)
* 围绕新剧情脉络、TRPG 规则与宇宙未解之谜展开异步交流与提案表决。

## 💡 创作须知与规范

1. **白皮书基准**：创作新人物、势力或故事时，建议先通读 `00 白皮书` 确立的宇宙物理法则（如流变星带、蓝悼异象、以太树特性与跃迁星图限制）。
2. **格式建议**：所有文档均采用标准 Markdown 格式编写。
3. **欢迎加入**：如有任何疑问或想加入世界观构筑团队，欢迎在 Issues / Discussions 留言或联系管理员！
